# Security

Please do not publish authentication material in GitHub issues, discussions or
logs. Kress Fleet and Home Assistant captures can contain passwords, cookies,
XSRF tokens, OAuth authorization codes, MQTT tokens/signatures, camera access
tokens, ICCID/IMSI values and authenticated request headers.

For a suspected security issue in the integration itself, contact the repository
maintainer privately using the contact method configured on their GitHub profile
instead of opening a public issue containing secrets.
